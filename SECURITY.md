# Security Policy

## Supported versions

Security fixes are provided for the latest published minor version of FlowerKit. Upgrade to the latest release before reporting an issue that may already be resolved.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Email `me@web3r.ru` with:

- the affected FlowerKit version;
- the affected utility or package entry point;
- steps to reproduce the issue;
- the expected impact;
- any suggested mitigation, if available.

You will receive confirmation after the report has been reviewed. Public disclosure should wait until a fix or mitigation is available.
